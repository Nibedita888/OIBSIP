# Aura — Modern Workspace Solutions

## 📌 Project Overview

Aura is a modern and responsive landing page designed for a productivity and workspace management platform.

This project was created as part of the **Oasis Infobyte Web Development Internship — Level 1, Task 1**.

The main goal of this project is to demonstrate fundamental **HTML5 and CSS3** skills by creating a clean, attractive, and responsive landing page.

## 🎯 Objective

To build a visually polished static landing page with:

- Sticky navigation bar
- Hero section
- Call-to-action buttons
- Feature section
- About section
- Testimonials
- Footer with contact and social links
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Google Fonts — Inter

## ✨ Features

### Navigation
- Sticky navigation bar
- Features, About Us, and Testimonials links
- Get Started call-to-action button

### Hero Section
- Main headline
- Supporting description
- Start Free Trial button

### Features Section
Includes three key features:

1. Smart Automation
2. Real-Time Sync
3. Advanced Analytics

### About Section
- Introduction to Aura
- Uptime statistics
- Active user statistics

### Testimonials
Two sample customer testimonials are included to make the landing page more realistic.

### Responsive Design
The website adapts to different screen sizes using CSS media queries, Flexbox, and Grid.

### Footer
Contains:
- Brand information
- Social media placeholders
- Contact information
- Copyright information

## 📱 Responsive Design

The website is designed to work on:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet

The layout automatically adjusts at smaller screen widths to prevent overlapping and maintain readability.
