# 💼 Nibedita Maji — Personal Portfolio

## 📌 Project Overview

This project is a modern and responsive personal portfolio website created to showcase my skills, projects, interests, and contact information.

The portfolio features a clean, professional, and user-friendly design that works across desktop, tablet, and mobile devices.

This project was created as part of the **Oasis Infobyte Web Development Internship — Level 1, Task 2**.

## 🎯 Objective

The main objective of this project is to create a professional personal portfolio website that presents:

- Personal introduction
- About Me section
- Technical skills
- Projects
- Contact information
- Professional and consistent branding
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Google Fonts

## ✨ Features

### 👩‍💻 Profile / Hero Section

- Name and professional role
- Short professional introduction
- Profile image/avatar area
- Clear call-to-action

### 📖 About Me

- Personal introduction
- Background and interests
- Professional overview

### 🛠️ Skills

The portfolio includes a visual presentation of technical skills such as:

- HTML
- CSS
- Python
- Git & GitHub
- Responsive Web Design

### 💼 Projects

The project section includes project cards containing:

- Project title
- Project description
- GitHub link placeholder

### 📩 Contact

The contact section provides options to connect through:

- Email
- GitHub
- LinkedIn

### 📱 Responsive Design

The website is designed to work smoothly on:

- 💻 Desktop
- 📟 Tablet
- 📱 Mobile

CSS media queries, Flexbox, and Grid are used to create a responsive layout.
