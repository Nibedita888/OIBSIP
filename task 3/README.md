# 🌡️ Temperature Converter

## 📌 Project Overview

Temperature Converter is a simple and user-friendly web application that allows users to convert temperatures between different units.

This project was created as part of the **Oasis Infobyte Web Development Internship — Level 1, Task 3**.

## 🎯 Objective

The main objective of this project is to create an interactive temperature conversion tool using fundamental web development technologies.

## ✨ Features

- 🌡️ Convert temperature values easily
- 🔄 Supports multiple temperature units
- 🖥️ Simple and user-friendly interface
- 📱 Responsive design
- ⚡ Quick conversion results
- 🎨 Clean and modern layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🌡️ Temperature Units

The converter can be used for common temperature units such as:

- Celsius
- Fahrenheit
- Kelvin
